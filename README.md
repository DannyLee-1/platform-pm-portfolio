## ORBIT에서 설계한 것

| 영역 | 내용 |
|---|---|
| **양면 사용자** | 아이디어 보유자 ↔ 합류 희망자의 서로 다른 진입·의사결정 흐름 |
| **핵심 퍼널** | 아이디어 입력 → 프로젝트 생성 → 후보 선택 → 초대·응답 → 궁합 → 합류 합의 |
| **신뢰 장치** | 결과물 검증, 아이디어 보호, 답변 후 궁합 공개, 역할·기여·보상 명시 |
| **운영 정책** | 초대 유효기간, 거절, 재생성 제한, 정보 공개 시점, 책임 범위 |
| **MVP 범위** | 한 역할·한 후보·한 합의 흐름을 우선 구현하고 단계별 데이터를 저장 |

> 추천 결과와 데모 지표는 제품 가설 검증용 시나리오이며 실제 운영 성과가 아닙니다.
