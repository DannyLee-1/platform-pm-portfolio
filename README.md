## 대표 프로젝트

### 01. ORBIT · 팀빌딩 매칭 플랫폼

> 아이디어는 있지만 어떤 역할과 팀원이 필요한지 모르는 사람을 위한 팀빌딩 서비스

| 구분 | 내용 |
|---|---|
| **역할** | 3인 팀 프로젝트 리더 · 문제 정의 및 서비스 설계 리드 |
| **문제** | 사용자는 필요한 역할을 설명하기 어렵고, 후보의 신뢰도와 합류 조건을 판단하기 어려움 |
| **검증** | 개발·디자인 경험이 거의 없는 비전문가 6명 설문 · 공개 실증 자료를 통한 공급자 가설 검토 |
| **핵심 판단** | 입력 부담을 낮추고, 추천 점수보다 **추천 근거·진행 증거·합류 조건**을 먼저 설계 |
| **실행** | PRD → IA → User Flow → Wireframe → 화면정의서 → Prototype → MVP 배포 |
| **결과** | 회원가입부터 프로젝트 구체화·후보 선택·합류 합의까지 핵심 여정 구현 |

**핵심 흐름**　`아이디어 한 줄` → `프로젝트 구체화` → `후보 추천` → `초대·응답` → `궁합 확인` → `합류 합의`

[**ORBIT 직접 체험하기 →**](https://portfolio-dannylee.vercel.app/demo)

### 02. 임산부 불빛 배려석 · 공공 서비스 설계

> 시민 의식의 문제가 아니라, 필요한 순간을 알 수 없게 만든 시스템의 문제로 다시 정의했습니다.

| 구분 | 내용 |
|---|---|
| **역할** | 문제 재정의·해결안·실행 설계·제안서 100% 단독 작성 |
| **문제** | 상시 공석과 양보 실패가 반복되지만, 운영은 개인의 선의와 눈치에 의존 |
| **핵심 판단** | 좌석을 늘리는 대신 버튼과 불빛으로 **필요한 순간만 보이게** 설계 |
| **실행** | 1분 자동 소등 · 시민 자율 교정 · 유지관리 · 접근성 · 좌석당 약 20만 원의 추정 원가 설계 |
| **결과** | **심사위원 전원 적격 · 서울시 아이디어풀 등재 대상 선정** |

[**제안서 보기 →**](https://portfolio-dannylee.vercel.app/file/%EC%9E%84%EC%82%B0%EB%B6%80_%EB%B0%B0%EB%A0%A4%EC%84%9D.pdf#page=1&view=FitH)

## 일하는 방식

| 1. 문제 | 2. 검증 | 3. 실행 |
|---|---|---|
| **잘못된 문제부터 만들지 않습니다.**<br/>해결책보다 먼저 “진짜 문제”를 되묻습니다. | **가장 위험한 가설부터 확인합니다.**<br/>논리의 빈틈과 실패 조건을 먼저 찾습니다. | **문서에서 멈추지 않습니다.**<br/>사용자가 움직이는 화면과 흐름으로 검증합니다. |

## ORBIT 설계 판단

| 설계 영역 | 적용 내용 |
|---|---|
| **진입 경험** | 첫 입력을 아이디어 한 줄로 줄여 초기 부담 최소화 |
| **신뢰 형성** | 결과물·평판과 함께 “왜 맞는지” 추천 근거 제시 |
| **정보 보호** | 후보 정보와 궁합 결과의 공개 시점을 단계별로 분리 |
| **합류 조건** | 역할·기여·보상 조건을 합류 전에 명확히 제시 |
| **MVP 범위** | 한 역할·한 후보·한 합의 흐름을 우선 구현 |

> 추천 결과와 데모 지표는 제품 가설을 확인하기 위한 시나리오이며, 실제 운영 성과가 아닙니다.
